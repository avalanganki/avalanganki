# Hi, I'm Ava Langanki

I'm a Data Analytics student at Syracuse University's School of Information Studies (graduating May 2027) and a Break Through Tech AI Fellow at Cornell Tech. I'm building toward a career in **AI and data consulting**, helping organizations turn their data into responsible, practical AI solutions. After graduation, I'm joining **Deloitte's Technology Transformation** practice.

**What I work on:**

- **Responsible AI systems:** recommenders and LLM tools that stay grounded, fair, and easy to evaluate
- **RAG and LLM applications:** retrieval pipelines, prompt design, and the Model Context Protocol (MCP)
- **Data analysis and visualization:** turning messy data into clear stories for decision-makers
